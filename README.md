# anime_inifinite_list

**Stack** : Next.js, React, Tailwind CSS, TypeScript

## Démarrage

```bash
npm install   # installer les dépendances
npm run dev   # serveur de développement
npm start   # démarrer
npm run build   # construire
npm run lint   # lint
```
